# AVS3DP GitHub Pages website

This folder is ready to publish as a GitHub Pages site.

## Publish with GitHub Desktop

1. Open the local folder for the `avs3dp.github.io` repository.
2. Replace the current website files with everything in this folder.
3. In GitHub Desktop, review the changed files.
4. Enter a summary such as `Launch new AVS3DP website` and select **Commit to main**.
5. Select **Push origin**.
6. The site will update at `https://avs3dp.github.io` after GitHub Pages finishes publishing.
